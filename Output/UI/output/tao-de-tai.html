Mô tả chi tiết đề tài

Đề tài nhằm xây dựng một hệ thống quản lý đơn hàng toàn diện cho sàn thương mại điện tử, bao gồm các chức năng quản lý sản phẩm, đơn hàng, thanh toán và vận chuyển.

Mục tiêu đề tài

  • Xây dựng RESTful API backend bằng Java/Spring Boot
  • Phát triển giao diện quản trị với ReactJS
  • Tích hợp hệ thống thanh toán và thông báo email
  • Triển khai CI/CD và unit testing

Công nghệ sử dụng

  • Backend: Java 17, Spring Boot 3.x, MySQL
  • Frontend: ReactJS, TailwindCSS
  • DevOps: Docker, Jenkins, AWS
