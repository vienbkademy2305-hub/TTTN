ℹ️
Kế hoạch đào tạo do Nhà trường đăng tải. Doanh nghiệp có thể xem và bổ sung ghi chú.
Tuần 1–2: Làm quen môi trường
  • Onboarding, tiếp nhận tài khoản và thiết bị
  • Đọc tài liệu hệ thống, codebase hiện tại
  • Họp kickoff với team và giảng viên hướng dẫn
Tuần 3–6: Phát triển tính năng
  • Phân tích yêu cầu và thiết kế database
  • Xây dựng các API endpoint
  • Unit testing, code review
Tuần 7–10: Hoàn thiện & Báo cáo
  • Hoàn thiện sản phẩm, fix bugs
  • Viết báo cáo thực tập
  • Báo cáo kết quả với giảng viên và doanh nghiệp
